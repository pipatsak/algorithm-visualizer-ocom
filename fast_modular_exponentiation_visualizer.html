Binary Exponentiation
long long powerMod(long long a, long long b, long long m) {
  long long res = 1; a %= m;
  while (b > 0) {
    if (b & 1) { // บิตต่ำสุดเป็น 1 (เลขคี่)
      res = (__int128)res * a % m;
    }
    a = (__int128)a * a % m; // ยกกำลังสองฐานเดิม
    b >>= 1; // เลื่อนบิตไปทางขวา (b /= 2)
  }
  return res;
}

ทำไมถึงเป็น O(log B)?

เพราะการเลื่อนบิต b >>= 1 คือการหารเลขชี้กำลังด้วย 2 ทุกรอบ จำนวนรอบการทำงานจึงเท่ากับจำนวนบิตของ $B$ หรือ $\lfloor\log_2 B\rfloor + 1$ (สำหรับ $B = 10^{18}$ วนเพียง 60 รอบ)

ทำไมต้องใช้ (__int128)?

หาก $M \approx 10^9$ หรือมากกว่า การคูณ res * a หรือ a * a จะได้ค่าถึง $10^{18}$ หรือมากกว่านั้น ซึ่งเสี่ยงล้นขอบเขตของ long long การ Cast เป็น (__int128) จะป้องกัน Overflow ก่อนการ % m ได้แน่นอน

การนำไปใช้หา Modular Inverse

ตามทฤษฎีบทของแฟร์มาต์ (Fermat's Little Theorem) หาก $M$ เป็นจำนวนเฉพาะ อินเวอร์สการคูณ $A^{-1} \pmod M$ จะมีค่าเท่ากับ $A^{M-2} \pmod M$ ซึ่งคำนวณผ่านฟังก์ชันนี้ได้ในทันที!
