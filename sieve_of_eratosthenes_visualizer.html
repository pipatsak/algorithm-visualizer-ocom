Optimized Sieve
void sieve(int n) {
  is_prime[0] = is_prime[1] = false;
  for (int p = 2; p * p <= n; p++) {
    if (is_prime[p]) {
      for (int i = p * p; i <= n; i += p) {
        is_prime[i] = false; // ตัดพหุคูณ
      }
    }
  }
}
void sieveNaive(int n) {
  is_prime[0] = is_prime[1] = false;
  for (int p = 2; p <= n; p++) {
    if (is_prime[p]) {
      for (int i = 2 * p; i <= n; i += p) {
        is_prime[i] = false;
      }
    }
  }
}

ทำไมเริ่มที่ i = p * p?

พหุคูณก่อนหน้าของ $p$ เช่น $2p, 3p, \dots, (p-1)p$ ถูกตัดทิ้งไปแล้ว โดยจำนวนเฉพาะที่เล็กกว่า $p$ การเริ่มที่ $p^2$ จึงช่วยประหยัดการวนลูปซ้ำได้อย่างมหาศาล

ทำไมใช้ vector<bool>?

ใน C++ มีการบีบอัดข้อมูลแบบพิเศษให้ 1 ช่องใช้หน่วยความจำเพียง 1 bit (แทนที่จะเป็น 1 byte) ทำให้ตะแกรงขนาด $10^7$ ใช้ RAM เพียงประมาณ 1.19 MB เท่านั้น

จุดระวัง Integer Overflow

เมื่อ $p > 46,340$ ค่า $p \times p$ จะเกินขอบเขตของ 32-bit Signed Integer ($2 \times 10^9$) หาก $N$ มีค่ามาก ให้ใช้ชนิดข้อมูล long long ในลูปตัดพหุคูณเสมอ
